====================================================
        AI新媒体工作台 · macOS 首次安装必看说明
====================================================

【第一步：安装到应用程序】
将本窗口中的「AI新媒体工作台.app」拖到右侧「Applications（应用程序）」文件夹中。


【第二步：首次打开提示“已损坏”或“无法验证开发者”怎么办？】
说明：本软件为免费本地工具，未购买 Apple 付费公证证书，macOS 会默认
拦截从网盘或浏览器下载的未公证应用，并非文件损坏，请放心按以下操作解除：

▶ 方法一（最推荐，5 秒解决，适用所有 macOS 版本）
  1. 按键盘 Command (⌘) + 空格，搜索并打开「终端」（Terminal）。
  2. 复制下面整行命令，粘贴到终端中并按回车键：

     xattr -cr /Applications/AI新媒体工作台.app

  3. 终端无报错即表示解除成功，现在即可从「应用程序」正常打开！

  * 若提示权限不足，改用下方命令并输入开机密码后回车（输密码时屏幕不会显示字符，直接输完回车即可）：

     sudo xattr -cr /Applications/AI新媒体工作台.app


▶ 方法二（系统设置放行）
  1. 先尝试打开一次应用（弹出提示后点「取消」或「完成」，不要点“移到废纸篓”）。
  2. 打开「系统设置」→「隐私与安全性」→ 向下滚动找到「安全性」区域。
  3. 看到“已阻止使用 AI新媒体工作台”提示后，点击「仍要打开」即可。


【补充提示】
1. 仅需操作一次：解除拦截后，以后每次打开都不会再提示。
2. 自动更新：软件内置国内高速自动更新，后续新版本可在软件内「设置 → 软件更新」一键升级。
3. 抖音视频洗稿：如需识别抖音本地视频画面，建议提前安装 FFmpeg（终端执行 brew install ffmpeg）。
4. 平台抓取说明：首次在设置页扫码登录抖音/小红书时，软件会在后台静默复用本机已安装的 Google Chrome / Microsoft Edge，无需安装 Python。
