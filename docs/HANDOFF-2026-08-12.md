## 核心产品流程

1. 选题：热点榜单与主动搜索；主动搜索只支持抖音、小红书，包含平台冷却与风险提示。
2. 创意：只从选题表的热榜条目导入，结合企业信息生成四个创作方向，再输出创意内容；DeepSeek 调用；可导出 Word、素材库与创意表。
3. 洗稿：链接解析 → AI 识别稿件 → 人工确认并填写洗稿要求 → AI 改写；抖音可本地下载视频并抽帧识别，小红书仅处理文案与图文/图片。
4. 提示词：导入洗稿表/创意表或 Word，生成纯图或图文提示词（1–9 张图片拆分）。
5. 出图：API（AIHubMix）为默认方式；本机 Codex 订阅仅在检测到本机能力时展示；生成任务及状态在切页后保留。
6. 素材库：用户本地目录下管理“选题、创意、洗稿、图片”文件夹；应用仅展示/打开，不删除或移动本地文件。

## 运行与验证

```bash
npm install --legacy-peer-deps
npm run dev
npm run typecheck
npm run build
```

- 构建安装包：`npm run dist:mac`、`npm run dist:win`。
- 构建前应配置本地更新源文件 `resources/update-source.json`（此文件已忽略，不在交接包内）。
- 功能验证应优先做真实低风险操作；不要仅以接口连通或目录存在认定可用。

## 本机首次使用与依赖

- 首次使用引导会检查并安装 Python、抓取/下载组件及 Chromium。
- 登录 Cookie 只保留在目标电脑本地；不要传入代码仓库、交接包、日志或对话。
- 外部依赖源码位于 `tools/MediaCrawler` 与 `tools/wechat-mp-tools`，运行数据、浏览器 Profile、虚拟环境均已从交接包排除。
- MediaCrawler 当前按非商业学习用途使用；继续开发时应保留许可证与平台规则边界。

## 安全与交接包排除项

- 不含 API Key、Cookie、浏览器资料、`.data/`、`.mc-data/`、外部工具 `data/`、虚拟环境、下载缓存、构建产物、`node_modules/`、本机更新源配置、日志。
- 目标电脑需要在“设置”页面重新填写模型 API Key，并完成平台登录。

## 开发约束

- UI 继续严格使用 HeroUI，沿用现有统一卡片、按钮、弹窗与状态反馈风格。
- 产品品牌只使用“AI新媒体工作台”；不要重新引入电信、广州电信、广信等表述。
- 选题与洗稿冷却分开计算；所有长任务在切换页面后应继续保持状态。
- 每次代码改动后至少执行 `npm run typecheck && npm run build`；涉及打包/更新时需要实际安装包验证。
