# AI 能力模型设置需求

| 项目 | 本批约定 |
|---|---|
| 设置首页 | 仅保留“AI模型设置”区，显示“文字改写、图片识别、视频识别、图片生成”四张卡片；每张卡展示当前供应商、模型与已保存/已验证/未配置状态。 |
| 类型配置 | 从卡片进入单层配置列表；每项以供应商和模型组成唯一选择，使用单选控件。显式选择后立即保存；新增配置不自动启用。 |
| 新建与编辑 | 配置归属进入时的能力。编辑当前项只替换该能力的活动项；编辑未启用项不改变活动项。取消不保存。 |
| 兼容与隔离 | 保留旧四能力选择及现有 provider/model/key/verified；不因缺少新索引而自动选择首项。已有配置只按能力兼容性列出；新增或编辑不得改变其他能力配置。 |
| 删除 | 当前使用项不可删除，先提示切换；删除非当前项只移除本能力引用，只有没有其他引用时才清理其专属密钥。 |
| 表单布局 | 标签置于控件外，模板来源使用只读展示；API 根地址全宽，单层弹窗在窄屏可滚动，正文至少 14px。 |

数据模型在现有 provider/model/key registry 上增加按能力维护的 `capabilityConfigs` 引用索引；现有 `providers` 与 `suppliers` 仍是配置及当前选择的事实来源。旧设置按现有活动 provider/model 派生索引，不迁移或读取真实用户文件。

视频仅允许现有 OpenAI Chat-compatible 配置；图片生成仅允许 Chat-compatible/OpenAI Images。Codex 独立入口及协议 adapter 不属于本批改造。
